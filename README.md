# Online Texas Hold'em

[在线游玩](https://texaspoker.thiopheneche.dpdns.org) | [项目总结](./summary.md) | [GitHub 仓库](https://github.com/thiopheneche/OnlineTexasPoker)

一个基于 `FastAPI + WebSocket + React + TypeScript` 的在线多人德州扑克项目，聚焦实时对战、轻状态大厅、顺畅的网页牌桌体验，以及较完整的德州规则流程实现。

## 当前已实现功能

### 账号与大厅

- 无注册访客式登录：输入唯一 ID 即可进入大厅，同一时刻同名 ID 只能在线一次。
- 浏览器本地仅保存最近登录过的 ID 与上次牌桌信息，但页面刷新或重新打开网站后不会自动静默登录。
- 多牌桌大厅：支持创建牌桌、加入牌桌、查看当前牌桌列表与游戏阶段。
- 自定义盲注：建桌时可设置小盲 / 大盲。
- 在线玩家展示：大厅实时显示当前在线人数与在线 ID。
- 大厅支持主动退出登录，方便切换账号；如果只是意外刷新或关闭页面，重新输入相同 ID 可直接续回原牌桌。
- 若本地记录的旧牌桌已经不存在，大厅不会再自动尝试接入该牌桌，避免卡死。
- 随时返回大厅：游戏中可以主动离桌返回大厅。

### 游戏与牌桌体验

- 完整基础流程：`PREFLOP -> FLOP -> TURN -> RIVER -> SHOWDOWN`。
- 开局准备机制：等待中的牌桌里，只有所有有筹码的玩家都点击“准备”后，才允许开始新的一局。
- 核心操作支持：`fold / check / call / raise / all-in / start`。
- 牌桌聊天：当前牌桌内实时聊天，带未读计数与聊天面板。
- 响应式布局：桌面端和移动端都尽量保持一屏内完成主要操作。
- 四排操作区：底牌、筹码信息、弃牌/跟注、加注/ALL-IN 分区明确。
- 当前轮次提示：牌桌顶部实时显示当前行动玩家。

### 筹码与局内机制

- 全局筹码系统：
  - 新用户初始获得 `5` 点全局筹码。
  - 创建牌桌消耗 `1` 点全局筹码。
  - 加入牌桌消耗 `1` 点全局筹码。
  - 离桌时按 `floor(当前手中筹码 / 1000)` 返还全局筹码。
  - 全局筹码会持久化保存到后端本地文件，服务器重启后不会丢失。
  - 后端会记录每个账号最近登录时间；若超过 `24` 小时未登录，则自动注销该账号。
- 断线保护与重连：
  - 刷新网页或意外断开时，牌桌座位会保留 `60` 秒。
  - 只有主动点击“返回大厅/退大厅/退出牌局”时才会发送离桌指令并立即结算。
  - `60` 秒内同一 ID 可直接回到原牌桌、原手牌和原筹码状态继续游戏。
  - 超时未重连则自动弃牌并结算离桌收益。
  - 其他玩家可看到掉线中的特殊标识。
- 破产与复活：
  - 每位玩家最多可复活 `3` 次。
  - 每次复活重新买入 `1000` 筹码。
  - 破产后有倒计时，可选择复活、观战或离桌。
- 终局胜者提示：桌上其余玩家全部彻底出局后，会触发终极赢家弹窗。

### 看牌、摊牌与展示

- 手牌默认盖牌，点击“看牌”可亮牌 `3` 秒后自动翻回。
- 默认盖牌样式已优化为红黑简约牌背，整张铺满显示区域，不露底、不留空隙。
- 弃牌获胜时，赢家可选择展示或隐藏自己的底牌。
- 正常摊牌时会展示公共牌、赢家原因、赢家分配结果，以及留到最后的底牌。

### 发两次与发牌动画

- `Run it Twice`：
  - 当玩家 `All-In` 且公共牌尚未发完时，第一个 All-In 的玩家可选择发一次或发两次。
  - 翻前发两次：两排各跑完整 `5` 张公共牌。
  - 翻牌后发两次：保留 flop，两排分别跑 turn + river。
  - 转牌后发两次：保留前四张，两排分别跑 river。
  - 河牌后 All-In：不再弹出发牌次数选择，直接正常结算。
- 发牌动画：
  - 公共牌会以翻牌动画进入牌桌。
  - All-In 后如果需要补 flop，flop 三张会同时发出。
  - turn / river 保持每张 `2` 秒的发牌节奏。
  - 双跑时会先完整发完第一排，再开始发第二排。

### 新手引导与说明文档

- 登录页提供网站使用教程入口。
- 大厅页提供网站新手教程入口。
- 游戏内提供德州扑克主要规则教程入口。
- 登录页与大厅页都提供反赌博声明与免责声明入口。

## 使用方式

1. 打开上方“在线游玩”链接。
2. 输入一个未被占用的游戏 ID 登录。
3. 在大厅中创建牌桌或加入现有牌桌。
4. 进入牌桌后开始对局，并使用聊天、看牌、加注、ALL-IN 等功能。
5. 如需快速熟悉网站或规则，可直接打开教程文档。

## 技术栈

- 后端：`FastAPI`、`Pydantic`、`WebSocket`
- 前端：`React 19`、`TypeScript`、`Vite`
- 样式：原生 `CSS`
- 实时通信：`WSS`
- 部署：`Cloudflare + Nginx + Uvicorn`

## 当前项目特点

- 以网页实时对战体验为核心，而不是传统数据库驱动的大型平台架构。
- 逻辑集中在后端原生扑克引擎中，规则实现相对直接、清晰。
- 前端交互以实用和顺畅为主，持续围绕牌桌体验做小步优化。

## 说明

- 当前没有账号密码体系，用户名即临时身份标识。
- 账号数据与全局筹码当前持久化在后端本地 `users.json` 文件中。
- 更完整的需求、结构说明与修改记录见 [summary.md](./summary.md)。
