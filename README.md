# 🃏 极速在线德州扑克 (Online Texas Hold'em)

一个基于 **FastAPI + WebSocket + React** 构建的轻量、实时、无状态的极速在线德州扑克全栈引擎。本项目抛弃了传统繁重的数据持久化层，专注于 **极致的在线竞技体验** 与 **纯正的德扑博弈逻辑**。

---

## ✨ 核心特性与功能 (Features)

### 1. 🛡️ 纯净的无状态访客登录大门 (Stateless Session Login)
- **用完即焚的 ID 机制**：抛弃繁琐的注册流程与数据库。玩家输入唯一 ID（如 `Player1`）后，通过全局心跳锁死该 ID。
- **即时释放**：只要玩家关闭网页、刷新或断网，心跳断开的一瞬间，该 ID 立刻被投回公共词库供他人认领。绝对保证在线防撞名与零历史包袱！

### 2. 🏛️ 多开房间大厅 (Multi-Table Lobby)
- **动态盲注建桌**：允许玩家根据财力自定义 **小盲注 (SB)** 和 **大盲注 (BB)** 级别，开启专属对局。
- **实时探测**：大厅自动轮询展示各个牌桌的信息、当前入座人数以及所处的游戏阶段。

### 3. ⚙️ 原生 Python 德扑硬核引擎
- 拥有完整、极度贴合德州扑克线下规则的状态机体系。
- **操作穷举校验**：服务器会拦截不合法的下注请求，严密管控 **Fold (弃牌)**、**Check (过牌)**、**Call (跟注)**、**Raise (灵活滑动加注)** 和 **All-In (全下)** 的所有临界条件及轮次递交。

### 4. 🫀 刺激的 3 秒挂起 All-In 决杀延时
- 当场上触发 **All-In** 殊死搏斗时，核心引擎切断同步结算，进入 **异步 (Async) 发牌协程**。
- 发牌员会依次翻开 **翻牌 (Flop)、转牌 (Turn)、河牌 (River)**，并且**在每一个阶段凝滞 3 秒钟**，让玩家心跳加速地祈祷绝杀牌的出现！在此期间无视一切前端干扰操作。

### 5. 💔 破产、重生与处刑倒计时
- **三次买入机制**：为玩家提供额外的 **3 次** 买入机会（每次 1000 筹码）。
- **生死时速 60 秒**：如果在对局中倾家荡产，屏幕将瞬间挂起血红的 60 秒倒计死线。超时未操作将被直接踢出房间！
- 若 3 次买入消耗殆尽，玩家将沦为**👁️ 幽灵观战模式**，眼睁睁看着对手瓜分底池。

### 6. 👑 终极赢家连庄机制 (Ultimate Winner)
- 引擎具备全局横向扫描能力。一旦全桌其余对手耗尽买入死绝，系统将引爆全屏特效宣告你的 **👑 绝对征服 👑**。
- 赢家面临最高荣誉的抉择：
  - **带着荣誉离开**：卷走所有筹码回到大厅深藏功名。
  - **傲视群雄 (留桌)**：利用庞大的“深筹码体系”留守残局，静待拿着 1000 块的新菜鸟误入此桌并在随后被无情碾压。

### 7. 📸 巅峰结算大合影
- 每局游戏结束时，弹出信息爆炸的结算面板：
- 居中呈现 **5 张决定命运的公共牌**。
- 公开**所有坚持到最后摊牌的玩家名称和两张底牌**。
- 清晰列出成牌类型与巨额的分赃金额，绝不错过任何一丝成就感或被 BadBeat 的不甘！

## 🚀 快速启动指南 (Quick Start)

### 后端 (Backend) - FastAPI
1. 确保安装好 Python 3.9+ 环境。
2. 安装依赖：
   ```bash
   cd backend
   pip install -r requirements.txt
   ```
3. 启动异步服务器：
   ```bash
   uvicorn main:app --reload
   ```
> 服务器将运行在 `http://localhost:8000` 并开放全局 `ws://` 端口。

### 前端 (Frontend) - React + Vite
1. 确保安装好 Node.js。
2. 安装依赖并启动开发服务器：
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
3. 打开浏览器访问控制台内提供的网址（默认一般为 `http://localhost:5173`），输入你的名字，随时开战！
